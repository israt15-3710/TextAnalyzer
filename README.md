## Text Length Checker ##  
About the Project: (Info)
Simplify, Text Length Checker is a simple web application built using HTML, CSS, and JavaScript. It allows users to enter text and check the number of characters. It can also detect whether the user entered a single word or multiple words. This project is designed for basic JavaScript functions, conditions, loops, and HTML elements

	Features:
	Simple and user-friendly design.
	Enter any text in the text box.
	Shows the character length of a single word.
	Shows the total character length and word count for multiple words.
	Displays an alert when the text box is empty.
	Works directly in a web browser.

	Technologies Used:

	HTML:  Creates the structure of the webpage.
	CSS: Makes the webpage look attractive.
	JavaScript: Checks the text and displays the results.

	How It Works:

Uses Some Step:

Step 1: The user enters text into the text box.
Step 2: The user clicks the "Check" button.
Step 3:  JavaScript reads the entered text.
Step 4:  The trim() function removes spaces from the beginning and end.
Step 5:  The program checks three conditions:
Condition 1: If there is only one word, it displays the length of that word.
Condition 2: If there are multiple words, it displays the total character length and word count.
Condition 3: If the text box is empty, it displays an alert message.
Step 6: The result appears below the button.
